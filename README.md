# PML Pelit

Hassu sivusto pienten nettipelien kehitykseen tai pelien esittelyyn.

> [!IMPORTANT]
> Sivustolla ei ole tekemistä minkään oikeiden paikkojen tai henkilöiden kanssa ja
> kaikki yhteneväisyydet ovat sattumaa.

## PML Sanasotkupeli

Sanapeli, jossa tehtävänä ratkaista satunnaisesti sotkettuja sanoja.
Sanat ovat lukioaiheisia.
